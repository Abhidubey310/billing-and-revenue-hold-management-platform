# Generic Business Rules

These rules are independently recreated for portfolio demonstration and are not derived from any employer's operating procedure.

## Classification hierarchy

1. Missing purchase order → Commercial Documentation
2. Service not ready → Service Readiness
3. Credit review or block → Credit Control
4. Contract under review → Contract Review
5. Suspected duplicate → Potential Duplicate
6. Awaiting customer confirmation → Customer Dependency
7. Source-data issue → Data Quality
8. No reliable match → Unclassified Exception

The first valid rule in the hierarchy determines the category.

## Owner assignment

| Hold category | Owner team |
|---|---|
| Commercial Documentation | Account Management |
| Service Readiness | Delivery Operations |
| Credit Control | Credit Team |
| Contract Review | Commercial Operations |
| Potential Duplicate | Billing Operations |
| Customer Dependency | Account Management |
| Data Quality | Revenue Operations |
| Unclassified Exception | Billing Operations |

## Priority model

- **Critical:** 120+ days old or value of 75,000+
- **High:** 60+ days old or value of 40,000+
- **Medium:** 30+ days old or value of 15,000+
- **Low:** all remaining cases

## Control principles

- Every case receives one category, owner, action, priority, and explanation.
- Unclear cases are routed for manual review rather than guessed.
- Revenue value supports prioritisation but does not determine accounting treatment.
- Recommendations require human review before operational action.
